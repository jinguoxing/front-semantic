# 数据质量需求（V1）

本文档用于梳理数据质量能力的 V1 版本需求范围，作为后续产品设计与实施的基础。

## 0. 模块清单与页面结构（V1）

### 0.1 模块清单

- 质量规则管理（配置、启停、模板）
- 质量执行管理（手动/定时/规则集）
- 质量结果与报告（趋势、问题明细）
- 告警与闭环（通知、处理、复检）
- 权限与审计（操作记录、权限控制）

### 0.2 页面结构

- 数据质量总览
- 质量规则配置
- 质量执行中心
- 质量报告
- 问题详情
- 告警与工单
- 系统设置（权限与审计）

## A. 质量规则管理页面（V1）

### A.1 页面目标

- 完成规则的创建、编辑、启停与分组管理
- 支持表级/字段级规则配置
- 支持规则模板与规则集的复用

### A.2 页面区块

- 顶部操作区：新增规则、导入/导出、批量启停
- 筛选区：关键字、规则层级、质量维度、严重级别、状态、表/字段
- 规则列表区：核心字段展示与批量操作
- 规则详情/编辑区：规则参数、阈值、调度、通知
- 版本与变更区：最近变更与操作记录（简化）

### A.3 规则列表字段（建议）

- 规则名称/编码
- 层级（表级/字段级）
- 质量维度（六性）
- 规则类型
- 目标对象（表/字段）
- 严重级别
- 启用状态
- 最近执行结果（可选）
- 更新时间/更新人

### A.4 规则配置项

- 基本信息：名称、编码、描述、标签
- 规则层级与类型：表级/字段级 + 规则类型
- 目标对象：数据源、库、表、字段
- 规则参数：范围/枚举/正则/外键等
- 阈值与容忍度：通过率、偏差阈值
- 调度方式：手动/定时/实时
- 通知策略：渠道、接收人、触发条件
- 启停控制：立即生效/延迟生效

### A.5 交互与校验规则

- 不同规则类型只展示对应参数（字段联动）
- 字段级规则必须选择字段，表级规则不允许选字段
- 阈值与参数冲突时提示（如范围上下限反转）
- 正则/枚举/外键配置需校验格式
- 支持规则复制生成新规则

### A.6 MVP 约束

- 先支持规则创建、编辑、启停、复制、删除
- 导入/导出为可选能力（仅 JSON/CSV）
- 版本管理仅记录最近一次变更

## 1. 范围与对象

- 质量对象：数据源、库、表、字段、规则集
- 支持环境：生产、测试（可扩展预发布）
- 质量维度：完整性、准确性、一致性、时效性、唯一性、有效性（六性）

## 2. 规则体系

### 2.1 规则类型

- 空值检查
- 范围检查
- 枚举检查
- 格式/正则检查
- 唯一性检查
- 外键/参照完整性检查
- 行数检查
- 分布检查
- 数据漂移
- 时效检查
- 业务规则（表达式）
- 自定义 SQL

### 2.2 规则层级

- 表级规则
- 字段级规则

### 2.3 规则配置

- 规则参数（如范围上下限、枚举值、正则）
- 阈值与容忍度（如通过率、最大偏差）
- 规则严重级别（严重/高/中/低）
- 规则启停
- 规则模板与规则包复用

## 3. 执行与调度

- 手动执行
- 定时执行（每日/每周/每月）
- 实时执行（可选，适用于关键指标）
- 规则集批量执行
- 运行超时控制与失败重试（简化版）

## 4. 结果与诊断

- 质量评分：总分与分维度得分
- 结果统计：通过/失败/预警数量
- 问题明细：命中规则、影响对象、影响范围
- 样本数据抽样（可选）
- 趋势分析：按周期查看变化

## 5. 告警与闭环

- 告警触发：按严重级别与阈值
- 通知渠道：邮件/短信/Webhook
- 责任人配置
- 修复跟踪：问题状态、处理记录、复检（简化版）

## 6. 治理与审计

- 规则版本记录（变更前后对比）
- 规则变更记录（谁、何时、为何）
- 权限控制（查看/编辑/执行）
- 操作审计日志

## 7. 可视化与报表

- 质量总览仪表盘
- 维度分布、Top 问题、热点表/字段
- 报告导出（CSV/PDF）

## 8. 集成与扩展

- 与元数据/血缘/语义层联动
- API 接口（查询、配置、执行、结果）
- 与数据治理系统对接（可选）

## 9. V1 交付边界

- 重点能力：规则配置、执行、基础报告、告警通知
- 非重点能力（放到 V2）：复杂审批流、多环境隔离策略、自动修复建议

## 10. V1 术语说明

- 质量对象：可被规则检测的数据实体（表、字段等）
- 规则集：一组可批量执行的规则配置
- 通过率：规则检测成功记录占比
